# 設計と物語

## ねらい

そろばんのフェスティバルの「関所めぐり」——時代劇のセットの中に問題が置いてあり、正解すると次の場所を教えてもらって、
セットの中を走ってさがす——あの楽しさを、学びのアプリに入れる。
決めたものを何度もくり返して、身にしみこませる（薫習）ための、ゲームの土台。

## 分け方

| もの | 持ち主 |
|---|---|
| コース・関所・チェック項目・進み具合・クリア・周回・ご褒美 | `@shiodome47/sekisho`（データも計算も、そのまま使う） |
| 町・通り・名所・関所の立つ場所・動き・道案内・登場人物・話 | この部品 |
| 項目の中身（区間の練習・問題）、保存先 | アプリ（`targets`・`onChange`・`onSave`） |

- 関所を立てる場所は `placeGates(town, course, lap)` が決める。同じコース・同じ周なら同じ場所、周が変わると場所も変わる
- クリアの演出は sekisho の `<Celebration>`。町は、クリアの記録が増えたのを見て出す（自分で押したときも、アプリが `report()` で進めたときも同じ）
- コースを制覇したときの演出（コースのご褒美）は、すぐには出さず、**城に着いたとき**に出す。制覇の記録はデータにあるので、途中で閉じても、次に城へ行けば出る
- 町の中の進み具合（`TownSave`）: いる場所・見つけた関所・見た話だけ

## 町「城下町」

```
  茶屋横丁 ── 寺町
     │          │
  木戸 ─ 本町通り ─ 大手門前 ─(門)─ 城内
     │          │
   川端 ──── 蔵屋敷
```

通りは横に長く、手前に歩ける帯がある。右・左のはし、奥（路地・橋・門）、手前（石の道）で、となりの通りへ。
名所は 20（旅籠・高札場・火の見やぐら・茶屋・井戸・芝居小屋・山門・鐘つき堂・大いちょう・船着き場・道場 など）。

絵はすべて `src/ui/draw.ts` で、形と色から描いている（画像のファイルは、登場人物だけ）。

## 物語（たたき台。いっしょに直していく）

**題**: 関所めぐり 城下町の巻

**登場人物**（名前は仮。`cast` で変えられる）

- **風太（ふうた）** — 主人公。風呂敷ひとつで城下町にやってきた子。わざをみがきたい
- **ご隠居** — 町の世話役。祭り「関所めぐり」の元締め。通行手形をくれる。じつは……
- **竹丸（たけまる）** — 道場の子。ライバル。先に町を走り回っていて、口は悪いが関所の場所を教えてくれる

- **関所の番人** — 関所のわきに立ち、印を押してくれる
- **町の人** — 茶屋の娘（茶屋）・呉服屋の主人（呉服屋）・寺の小僧（山門）・船頭（船着き場）。話しかけると、ひとことと、関所の場所のうわさ

**流れ**

1. **序（町の木戸）** 年に一度の「関所めぐり」の日。ご隠居が通行手形をくれる。
   「香りが 衣に しみるように、くり返した わざは 身に しみる。あせらず、何度でも じゃよ。」
2. **破（町じゅう）** 関所をさがして走る。関所で稽古（くり返し）をすませると、番人が印を押して、次の場所を教える。
   竹丸は、こえた関所の数に合わせて通りを移っていく
3. **急（城）** 印が全部そろうと、大手門が開く。城で待っていたのは、ご隠居。じつは城のあるじ（殿さま）だった。
   ここで、コースのご褒美（動画など）が出る
4. **結** 「次の祭りでは、関所の場所がかわるぞ」→ もう一周（sekisho の周回）

せりふは `src/ui/labels.ts` に全部ある（`intro`・`guideTalk`・`rivalTalk`・`afterClear`・`finale`・`ending` など）。
学ぶ中身に合わせて変えるときは、`labels` で差し替える。「わざ」「稽古」「印」は、手話でも、そろばんでも、Cardano でも使える言葉にしてある。

**これから考えたいこと**

- 名前（風太・竹丸・ご隠居）と、町の名前
- 巻ごとの話（手話の巻・そろばんの巻で、はじめと終わりのせりふを変えるか）
- 竹丸との競争（先に印を集めるなど）を入れるか

## これから

- 音の素材を選んで入れる（差込口 `onSound`・`createSoundPlayer` はある。素材は、使ってよい条件を確かめて、アプリの側に置く）

- 町の人・番人の絵、店に入る、季節・時刻
- 通りを増やす・別の町（宿場町・港町）
- sekisho の作る画面で、関所を立てる名所を選ぶ
